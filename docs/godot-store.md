# Godot Asset Store release

Use the **Wordsmith Engine** listing under B.T. Franklin's publisher account.
Select **Addon**, the MIT license, and free distribution. Set the supported
engine range to 4.7 through 4.7.x. Use the 16:9 thumbnail in
[the Store media directory](../packages/gdscript/store/thumbnail.jpg).

## Listing text

Generate English names and titles in GDScript. Make names for people, ships,
towns, creatures, and spells. Combine words and generators to make your own
text. Supply a seed to repeat a sequence in Godot, or use a SHA-256 digest
to generate the same person name in GDScript, Python, and TypeScript.

Example output from the included game is “Relentless Hound of Phoenix Harbor.”
Use the tags GDScript, procedural generation, and text. Link the
[source repository](https://github.com/btfranklin/wordsmith-engine) and
[Godot package guide](https://github.com/btfranklin/wordsmith-engine/tree/main/packages/gdscript).
Disclose that AI assisted with the GDScript port, tests, and documentation.

## Publish and verify

1. Wait for the tag workflow to finish. Check the release notes and the Godot
   ZIP on the draft before publishing it.
2. Download the attached ZIP from the published release. Upload that file
   under **Versions**. Use the tag number without the leading v. Copy the
   release notes and submit the listing for review.
3. Record the submission date, version, and review status in the GitHub
   release notes. A moderator controls when the listing becomes public.
4. After approval, install that version from the Store in a clean Godot 4.7
   project. Run the ship example and verify the output above. Add the public
   listing link and verification date to the release notes.

Follow the [Godot submission guide](https://docs.godotengine.org/en/stable/community/asset_store/submitting_to_asset_store.html)
for publisher setup, media, and moderation.
